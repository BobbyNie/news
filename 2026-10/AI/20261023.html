报告范围

本窗口的主线是企业 AI 采购从单一模型转向多模型、云内治理和场景专用化。金融机构案例显示，开放模型、银行自有数据、专用小模型和可审计评估正在组合成生产路径。

今日最重要的 5 条

  1. P0｜模型分发

    OpenAI 模型进入 Google Cloud Model Garden

    OpenAI 官方说明称，前沿模型和 Codex 智能体工作流将进入 Google Cloud Model Garden。企业可以在熟悉的云基础设施、访问控制和数据治理框架中使用这些模型。该变化把模型能力、云治理和企业采购放进同一条路径。

    来源：OpenAI、Google Cloud

  2. P0｜金融 AI

    欧洲金融机构公开展示开放模型与自有基础设施

    NVIDIA 汇总的案例包括 Revolut、Starling Bank、Lloyds、bunq、NatWest、Santander、HSBC 和 Stripe。公开方向覆盖交易基础模型、支付、欺诈检测、客户服务和内部运营。重点不是单一模型排名，而是机构如何控制数据、成本和部署环境。

    来源：NVIDIA

  3. P1｜Agent

    Claude Duet 进入研究预览

    Anthropic 发布说明显示，Claude Duet 研究预览面向 Pro 和 Max 用户开放。产品定位为主动代理。研究预览不等同于企业稳定版本，因此后续应检查权限隔离、任务成功率、人工审批和审计能力。

    来源：Anthropic 发布说明

  4. P1｜云平台

    Anthropic-managed Claude on Google Cloud 一般可用

    Anthropic 官方页面称，Google Cloud 上的 Anthropic-managed Claude Platform 已一般可用。企业可以把 Claude 平台能力与 Google Cloud IAM、计费和承诺抵扣结合。该路径降低了多云采购和治理的切换成本。

    来源：Anthropic

  5. P1｜银行 AI

    Santander 用模型评估和专用小模型推进银行 AI

    Santander AI Lab 使用 Model Arena 评估银行模型和 Agent，并在客服场景测试专用小模型。官方披露还涉及反欺诈和反洗钱方向。该案例说明银行生产化需要评估层、场景模型和基础设施同时建设。

    来源：Santander

模型、产品、Agent 与开发者工具

模型与产品

本窗口未出现足以重新排列基础模型能力的公开基准。更重要的产品变化是 OpenAI 模型进入 Google Cloud Model Garden，以及 Claude Platform 的 Anthropic-managed 版本一般可用。企业可以从“选一个模型”转向“按数据、权限、延迟和成本选择模型”。

Agent 与执行

Claude Duet 进入研究预览。执行型 Agent 仍需要最小权限、沙箱、人工审批、失败回滚和审计日志。研究预览只能证明产品方向，不能证明生产稳定性。

开发者工具

Google Cloud 的 Model Garden 路径把模型选择、访问控制、数据治理和云账单放在同一个采购界面。开发团队需要同时测试提示注入、代码依赖、密钥暴露和数据出境风险。
