分主题详情

模型竞争：Grok 4.5 把焦点放在工程与 agentic workflow

Grok 4.5 的核心不是消费者聊天噱头，而是 coding、agentic tasks 和 knowledge work。它把模型竞争从“谁更强”继续推向“谁能更低成本、更快嵌入工程流程”。这条线索需要明天继续跟踪 API 文档、价格、上下文能力和企业集成。

OpenAI：GPT-5.6 Sol 的事实边界必须写清

OpenAI 官方 preview 给出了能力、风险和 safeguard 叙事，尤其是 coding、生物和网络安全任务。但在正式 release note 或 API 文档更新前，日报只能写“更广泛发布预期/媒体报道”，不能写成所有用户已经可用。

设备 AI：Meta 眼镜报道显示场景扩大，也扩大合规面

持续感知设备让个人 AI 从检索助手变成环境助手，但音频、图像、提示灯和训练数据是硬风险。后续最关键的是 Meta 是否提供明确 opt-in、可见提示、数据最小化和禁用路径。
