  1. OpenAI 推出 ChatGPT Work，把 ChatGPT 进一步变成可交付成品的工作 agent。官方称它可跨应用和工作流收集信息，生成文档、表格、演示、报告和网站，并能把复杂项目拆成步骤长时间执行。Agent 产品 OpenAI
  2. OpenAI 引入 workspace agents，团队可在组织权限下创建共享 agent。这让 agent 从个人助手进入团队流程，权限、审批、Slack 集成和长任务可观测性会成为产品成败关键。企业工作流 OpenAI
  3. Meta 发布 Muse Spark 1.1，并启动 Meta Model API public preview。Meta 官方称开发者可访问 Muse Spark 1.1，模型也在 Meta AI app 和 meta.ai 的 Thinking mode 可用，显示 Meta 开始更直接地商业化模型能力。开发者 API Meta AI
  4. xAI / SpaceXAI Grok 4.5 继续锁定 coding、agentic tasks 与 knowledge work。官方页显示 Grok 4.5 可通过 Grok Build、Cursor 和 SpaceXAI console/API 使用，欧盟可用性预计 7 月中旬。模型发布 xAI
  5. Anthropic 将 Ben Bernanke 纳入 Long-Term Benefit Trust。前美联储主席加入独立监督机构，说明前沿 AI 公司正在把宏观风险、公共利益和董事会治理写进发布节奏。AI 治理 Anthropic
  6. AI 服务出口管制从芯片扩展到 API 与云服务。FT 报道 OpenAI 与 Google 的服务被部分受限制中国实体关联方使用，引发客户筛查、地区访问和模型蒸馏风险讨论。合规风险 Financial Times
  7. 金融 AI 应用继续从客服走向信贷分发和运营优化。Bajaj Finserv 股东信披露 bot calls 与 AI chat 在 FY26 生成贷款，银行和非银机构的对话式 AI 已进入收入流程。金融 AI Times of India

分主题详情

OpenAI：从聊天入口转向可执行工作平台

ChatGPT Work 和 workspace agents 的共同点是把“问答”降级为入口，把任务拆解、跨应用读写、团队共享和长时间执行放到中心。真正需要跟踪的是连接器权限、审批流程、错误回滚、审计日志和组织数据隔离，而不是单次回答的流畅度。

Meta：Muse Spark 1.1 把模型商业化压力推到前台

Meta 官方博客显示 Muse Spark 1.1 进入 Meta Model API public preview，这与过去偏消费和开放权重的叙事不同。若 API 定价和工具调用体验有竞争力，Meta 可以把巨额 AI 基建投入转化为开发者平台收入；若体验不稳定，市场仍会质疑 AI capex 回报。

xAI：Grok 4.5 已经不是单纯聊天模型故事

Grok 4.5 的官方定位直接指向 coding、agentic tasks 和 knowledge work，并已嵌入 Cursor。后续比较维度应从“是否聪明”转为价格、延迟、上下文、工具调用、企业权限和地区可用性。

金融业 AI 应用专栏（银行优先）

今天没有新的大型银行 AI 客户产品上线；金融 AI 增量在信贷分发与治理。

Bajaj Finserv 股东信案例显示，自动 bot calls 与 AI chat 已经可以进入贷款生成流程，关键不再只是节省客服成本，而是把对话数据、转化率、审批线索和风险控制串起来。银行侧仍以 HSBC 公开材料中的负责任 AI、欺诈防控、市场分析和个性化服务为可核验框架。 HSBC

治理重点：

金融机构若把 agent 或 AI chat 接入客户、信贷、财富管理和合规流程，必须同步处理客户同意、记录留存、模型输出解释、人工复核和第三方模型依赖。否则 AI 应用会从效率工具变成操作风险源。

风险与不确定性

  • OpenAI 的新 agent 能力需要以实际账户可用范围和企业权限文档为准，不能把产品愿景写成已经覆盖所有用户。
  • Meta Model API public preview 的价格、速率限制和企业 SLA 尚需继续核验。
  • FT 出口管制报道涉及 paywall 与后续官方回应，今天只作为合规风险信号。
  • 金融 AI 专栏不使用股价、IPO 或宏观内容填充。
