分主题详情

模型访问控制：从安全评测进入客户连续性

Anthropic 表示，美国政府指令要求暂停 Fable 5 和 Mythos 5 对外国国民的访问，范围包括美国境内和公司内部外国籍员工。公司称无法在现有服务中可靠地只切掉相关用户，因此选择对所有客户禁用两个模型。这个事件说明 frontier model 的风险不再只停留在 benchmark、safety card 或发布说明，而是会直接影响 API 可用性、云市场分发、跨境团队协作和客户合同。Anthropic

受监管行业：系统集成商成为 Claude 进入核心流程的入口

TCS / Anthropic 合作明确覆盖金融服务、公共部门、生命科学、医疗、航空、电信等行业，并点名保险 claims processing、银行 lending advisory。TCS 同时称将让 50,000 名员工使用 Claude。这类合作的关键不是“某个聊天机器人上线”，而是行业方案、权限、审计、实施和运维谁来承担。Anthropic · TCS

企业 agent：训练、环境和采购路径正在补齐

OpenAI Academy 的 Agents and Workflows 课程把“如何给 agent 设上下文、边界和评审”变成标准化培训；Ona 收购指向 Codex 的持久执行环境；Oracle OCI 合作则把 OpenAI models 与 Codex 接入企业既有云承诺。三件事连在一起，说明企业 agent 的短板正在从模型能力转向组织落地条件。OpenAI Academy · Ona · Oracle

垂直采用：教育案例强调人与 AI 的流程分工

Preply 使用 OpenAI 生成 lesson summaries、个性化反馈和练习，OpenAI 页面披露其员工和 tutor 采用数据。它的信号是：高频行业工作流更可能先通过“专业人员 + AI 辅助”扩散，而不是直接替代服务主体。OpenAI / Preply
