分主题详情

开发者工具：安全审核正在进入生成请求本身

  • OpenAI 的 moderation scores 更新不是 headline 模型能力，但对工程落地重要：开发者可以把输入、输出、审核结果、日志和告警压到同一次响应链路里。OpenAI release notes
  • 这会降低把安全审核做成事后补丁的概率，也便于企业在审计和合规流程中追踪单次生成的完整风险信号。

治理主线：AI 风险从模型评估扩展到供应链 chokepoint

  • 众院草案如果后续进入正式立法，重点不只是“管 AI”，而是把 frontier developer 风险计划、关键事故报告、CAISI 标准制定和州法协调放进一个联邦框架。Axios
  • 生物安全公开信则给出更窄但更可执行的监管落点：要求销售 synthetic DNA/RNA 的公司筛查客户和订单，堵住 AI 可能降低生物武器设计门槛后的物料环节。Fortune

平台竞争：Microsoft 和 Google 都在强调 agentic 开发栈

  • Microsoft Build 的七个 MAI 模型让它在 OpenAI 合作之外拥有更多自有模型选择；MAI-Thinking-1 进入 Foundry private preview 后，Azure、GitHub、VS Code 与 Copilot 的模型编排空间更大。Microsoft
  • Google 6/5 recap 把 Gemini、AI Studio、Managed Agents 重新放在一条线上，说明开发者平台竞争正在围绕 agent runtime、沙箱、持久环境和模型调用体验展开。Google
