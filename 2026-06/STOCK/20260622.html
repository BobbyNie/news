财报与指引

Micron 是本周 AI 硬件链最直接的 earnings catalyst。MarketWatch 摘要显示，市场预期其 May quarter adjusted EPS 年增接近 1,000%，背后是 AI-related memory chips 和 tight memory supply。真正需要看的不是单季同比本身，而是 HBM pricing、capacity、2027 supply、客户订单和毛利弹性。

继续跟踪：Micron 指引是否支持 AI memory shortage 继续存在；FedEx / FedEx Freight 是否给出宏观运输需求信号；Nvidia / server chain 是否随 Micron 指引同步反应。
