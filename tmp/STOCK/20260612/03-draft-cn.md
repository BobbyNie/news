# 2026-06-12 股市日报草稿

今天股市主线是“AI 云收入高增长是否足以覆盖资本开支”。Oracle 官方财报显示云基础设施收入高速增长、RPO 大幅增加，但市场媒体同时强调高 AI 数据中心支出、融资和自由现金流压力。OpenAI 与 Oracle 的 OCI 合作则说明 Oracle 的 AI 云故事不只是容量扩张，也在争企业采购入口和 Codex / 模型分发路径。

要闻：

1. Oracle Q4 总收入 192 亿美元、云收入 99 亿美元、IaaS 收入 58 亿美元且同比增长 93%，RPO 达 6380 亿美元。
2. Oracle FY2026 自由现金流为负 236.86 亿美元，资本开支压力成为市场定价焦点。
3. OpenAI 与 Oracle 合作，让 OCI 客户通过既有 cloud commitment 使用 OpenAI models 与 Codex。
4. WSJ 摘要显示 6 月 11 日美股大盘反弹，但 Oracle 因 AI 数据中心支出承压，说明 AI 交易内部开始区分收入质量和资本回报率。
5. OpenAI 收购 Ona 将 Codex 推向长任务、云端 agent 工作区，继续影响开发者工具和企业软件自动化估值框架。
6. 马斯克专题：媒体报道 SpaceX IPO 定价，同时 Guardian 报道 xAI 前工程师安全诉讼；TSLA 与相关主题需区分官方披露、法院文件和传闻。
7. 港股科技窗口内未见同等级 HKEX/IR 新公告，不能用美股 AI 反弹替代本地事实。

风险：

- Oracle 云增长强，但高资本开支和负自由现金流会让市场持续质疑 AI 云回报周期。
- OpenAI/Oracle 合作仍要看 OCI 上线节奏、客户转化、云承诺抵扣范围和毛利影响。
- SpaceX IPO 与 xAI 诉讼报道需要后续官方文件和法院进展复核。
- 港股科技缺少本地新增披露，外部 AI 情绪传导有限。
