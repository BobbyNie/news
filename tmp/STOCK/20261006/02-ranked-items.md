# 股市排序项目

## P1 — 市场时间与价格口径
- 事件：报告窗口跨越周末、美国收市和香港交易时段。
- 为什么重要：不同市场的收盘时间不同，盘中信息不能替代收盘数据。
- 可能影响：报告只写可核对的时间戳和来源，不填未验证的实时点位。
- 证据链接：https://www.reuters.com/markets/ ; https://apnews.com/hub/financial-markets

## P1 — 近期 IPO 文件闭环
- 事件：复核 SEC、Nasdaq、NYSE 与 HKEX IPO 入口。
- 为什么重要：发行价、募资、财务、基石/战略投资者、流通量、锁定期及诉讼风险必须来自原始文件。
- 可能影响：没有完整闭环的候选只能列为信息不足或暂不关注。
- 证据链接：https://www.sec.gov/search-filings ; https://www1.hkexnews.hk/app/appindex.html

## P1 — AI 基础设施订单与融资
- 事件：市场继续关注 AI 基础设施的订单、交付、融资和客户集中度。
- 为什么重要：主题热度不能替代公司披露和财务验证。
- 可能影响：若出现正式订单、指引或融资文件，才形成可追踪的事件驱动对象。
- 证据链接：https://www.sec.gov/search-filings ; https://www.reuters.com/markets/

## P2 — 港股公告与新上市证券
- 事件：检查 HKEX 交易日历、新上市证券和公司公告入口。
- 为什么重要：港股主题需要披露和成交证据共同支持。
- 可能影响：下一交易日补齐有时间戳的量价和公告信息。
- 证据链接：https://www.hkexnews.hk/ ; https://www.hkex.com.hk/Services/Trading/Securities/Trading-News/Newly-Listed-Securities?sc_lang=en
