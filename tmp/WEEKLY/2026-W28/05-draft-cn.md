# 2026 年第 28 周 AI + 股市周报草稿

本周核心不是单一模型，也不是单一指数行情，而是前沿模型、agent 产品、API 商业化、安全治理和 AI 半导体融资同时进入验证期。

AI 方面，OpenAI GPT-5.6 与 ChatGPT Work 让竞争焦点从 benchmark 移向知识工作 agent 的可用性、成本、权限和长任务可靠性。Meta Muse Spark 1.1 与 Meta Model API public preview 显示 Meta 开始用收费 API 承接 AI capex。xAI Grok 4.5 继续把 coding 和 agentic work 作为切入点。Anthropic 任命 Ben Bernanke、FLI 发布 AI Safety Index，则让安全治理成为模型竞争的第二条主线。

市场方面，7 月 10 日美股收盘仍温和上涨，S&P 500 周涨 1.2%，Nasdaq 周涨 1.7%，Dow 周跌 0.5%。SK Hynix ADR 首日涨约 12.8%，说明 AI HBM 供应链的大型融资获得资金承接。港股新股密集上市，Nexchip、Hesai-W、Befar 等事件确认硬科技融资窗口仍开，但 Luxshare 平淡表现提醒流动性并非无限。

AI 与市场的交叉影响集中在三点：模型能否变成可收费产品，算力和 HBM 供给能否继续支撑 AI capex，治理和访问控制是否影响模型可用范围。

周末美国和伊朗冲突推高油价、压低美股期货。这不是正式收盘，但会影响下周一开盘；真正的下一批证据来自 CPI、PPI、大型银行财报和 TSMC 财报。
