# AI 排序候选（2026-07-02）

1. P0｜Anthropic Fable 5 / Mythos 5 限制解除与部分保留
   - 为什么重要：前沿模型可用性从产品问题升级为出口管制、网络安全与客户审核问题。
   - 可能影响：企业采用高能力模型时需要将访问控制、地区合规、红队和用途审核纳入采购条件。
   - 证据链接：https://apnews.com/article/028db5135128fce6b38c873bf9cb5e09

2. P0｜Claude Sonnet 5 发布并进入 Claude Code / API
   - 为什么重要：中档模型的 agent 执行能力和价格会影响 coding agent、企业自动化与开发者平台选择。
   - 可能影响：开发者可能把更多长上下文、工具调用和多步骤任务迁移到较低成本模型。
   - 证据链接：https://www.anthropic.com/news/claude-sonnet-5

3. P1｜OpenAI GeneBench-Pro 测试科研判断
   - 为什么重要：benchmark 从答案正确率转向研究路径选择、模糊数据判断和后果性决策。
   - 可能影响：生命科学 AI 需要证明可审计分析流程，而不是只展示摘要与代码片段。
   - 证据链接：https://openai.com/index/introducing-genebench-pro/

4. P1｜SWE-Together 关注多轮真实 coding agent 互动
   - 为什么重要：真实开发中用户会补充约束、纠错和改变目标，静态任务无法充分测量。
   - 可能影响：agent 评估会从单次提交转向交互效率、澄清能力和长期维护质量。
   - 证据链接：https://huggingface.co/papers/2606.29957

5. P2｜Claude on GB300 in Azure 延续企业部署主题
   - 为什么重要：模型能力、云平台、GPU 供给和企业合规正在绑定。
   - 可能影响：Azure-native 客户获得另一路 Claude 部署路径，但成本、区域可用性和数据治理仍需确认。
   - 证据链接：https://blogs.nvidia.com/blog/anthropic-nvidia-gb300-blackwell-ultra-microsoft-azure/

6. P2｜金融机构 AI 应用无新增一手公告
   - 为什么重要：银行 AI 专栏不能用股价、利率或 IPO 噪音填充。
   - 可能影响：今日只记录已检查来源与缺口，继续等待银行、支付、券商或监管科技一手发布。
   - 证据链接：https://www.hsbc.com/who-we-are/hsbc-and-digital/hsbc-and-ai
