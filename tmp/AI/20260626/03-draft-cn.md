# 2026-06-26 AI 日报草稿

今天 AI 主线不是新聊天功能，而是 agentic work、推理芯片、生产级基础设施和金融机构落地。

OpenAI 的两条官方更新构成最强信号。第一，OpenAI 与 Broadcom 发布 Jalapeno 推理芯片，表示工程样片已在实验室运行 ML 负载，并计划与伙伴在 2026 年开始 gigawatt-scale 部署。第二，OpenAI 发布 agentic work 研究，把 Codex 这类工具定位为可委派、长周期的工作单元，并给出内部和组织用户的采用数据。

NVIDIA 则把 agent 生态进一步产品化。AWS 方向，NVIDIA 将 Blackwell GPU、cuVS 向量索引和 GB300 训练性能包装为生产级云基础设施；企业方向，Agent Toolkit 和 BioNeMo Agent Toolkit 体现了模型、工具、技能、运行时的组合；电信方向，NVIDIA 用 synthetic data、secure runtime 和 simulation 说明运营 agent 需要治理和审计。

金融业 AI 应用方面，Lloyds 和 HSBC 是今天最清晰的银行样本。Lloyds 宣布接近 300 个 agentic AI 相关岗位和 AI Academy 培训进展，说明银行 AI 需要内部人才和责任框架。HSBC 与 Google Cloud 的合作继续值得跟踪，因为其重点不是抽象效率，而是金融犯罪风险管理、财富管理和前线团队支持。

风险方面，OpenAI 自研推理芯片仍缺少独立性能测试，NVIDIA 的 toolkit 需要实际客户 ROI 验证；银行 AI 的关键约束仍是模型风险、隐私、审计、员工责任和监管接受度。
