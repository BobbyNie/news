# 2026-06-12 AI 日报草稿

今天 AI 主线从“模型发布”转向“企业可控部署和受监管行业落地”。OpenAI 用两条公告把 Codex 和模型分发推进到更深的企业环境：一是收购 Ona，为 Codex 提供长期运行和客户可控的云端工作区；二是与 Oracle 合作，让 OCI 客户可用既有云承诺访问 OpenAI 模型和 Codex。Anthropic 则通过 DXC 把 Claude 带入银行、保险、航空、制造和政府机构依赖的系统，强调现场工程、合规和托管运维。

要闻：

1. OpenAI 宣布收购 Ona，扩展 Codex 的 secure、customer-controlled cloud infrastructure 和 long-running agents 能力。
2. OpenAI 与 Oracle 合作，让 OCI 客户通过既有 Oracle cloud commitment 使用 OpenAI frontier models 和 Codex。
3. Anthropic 与 DXC 建立多年全球联盟，DXC 将训练数万名 Claude-certified FDE，把 Claude 集成到大型银行、保险和政府等受监管系统。
4. OpenAI 披露疑似 PRC 关联影响行动瞄准 AI 数据中心、电价、关税和美国技术政策叙事，显示 AI 基础设施已成为舆论安全对象。
5. Oracle FY2026 Q4 显示 IaaS 收入同比增长 93%，RPO 达 6380 亿美元，继续验证 AI 云和数据中心容量需求。
6. 金融业 AI 专栏：窗口内未见银行官方新客户服务、财富管理、信贷审批或合规 AI 产品；DXC/Claude 是受监管行业系统集成信号，HSBC 官方 AI 页作为银行采用基线。

风险：

- OpenAI/Ona 收购仍待整合，不能直接等同于 Codex 新功能马上全面可用。
- OpenAI/Oracle 合作的真实影响取决于 OCI 上线节奏、可用区域、权限、定价和企业采购转化。
- DXC/Anthropic 还没有披露具体银行客户或上线系统，金融业影响需要后续官方案例验证。
- Oracle 云收入和 RPO 是基础设施需求信号，但资本开支和交付能力仍是约束。
