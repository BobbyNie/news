# AI 排序项目

## P0
- 事件：企业 Agent 进入上下文、权限和工作流竞争。
- 为什么重要：Atlassian 与 OpenAI 的合作把模型能力接入团队工作流。企业购买对象从聊天界面扩展到任务系统。
- 可能影响：权限继承、索引更新、审计和部署成本将影响大规模采用。
- 证据链接：https://openai.com/index/atlassian-partnership/

## P1
- 事件：企业模型把控制面和成本治理放入产品定义。
- 为什么重要：Cohere 的企业定位强调安全、部署位置和成本控制。
- 可能影响：模型路由、数据位置和单位任务成本会成为采购评估项。
- 证据链接：https://cohere.com/blog

## P1
- 事件：内容溯源从研究主题进入产品和合规讨论。
- 为什么重要：文本水印、开放标准和验证工具形成组合方案。
- 可能影响：企业需要区分模型生成、人工编辑、外部转载和验证失败。
- 证据链接：https://openai.com/index/eu-text-provenance/

## P1
- 事件：ChatGPT Ads 进入广告主使用流程。
- 为什么重要：广告产品需要同时处理商业化、用户隐私和回答可信度。
- 可能影响：广告与回答的分离、数据边界和聚合报告是持续观察点。
- 证据链接：https://ads.openai.com/；https://help.openai.com/en/articles/20001047-ads-in-chatgpt

## P2
- 事件：银行 AI 采用继续围绕服务与治理。
- 为什么重要：公开页面显示客户服务、风控、内部工具和责任治理的长期建设。
- 可能影响：模型风险、数据权限、供应商依赖和审计能力限制扩展速度。
- 证据链接：https://info.bankofamerica.com/en/digital-banking/erica；https://www.dbs.com/artificial-intelligence-machine-learning/artificial-intelligence/ethical-and-responsible-ai-in-banking.html
