# AI 候选排序

1. P0 — NVIDIA 推出 AI compute 融资与多租户供给模式。
   - 重要性：算力供给从纯技术和长期租约扩展到资本、信用与收入分成安排。
   - 可能影响：新模型公司更容易获得大规模 GPU，但 NVIDIA 与 AI clouds 承担更多利用率和信用风险。
   - 证据：https://blogs.nvidia.com/blog/nvidia-unlocks-ai-compute-at-scale-capital-partners-to-power-ai-infrastructure-buildout/
2. P1 — NVIDIA 进一步本地化美国 AI 基础设施供应链。
   - 重要性：覆盖晶圆、封装、光通信、系统和 AI factory 多层供给。
   - 可能影响：AI 基础设施竞争更依赖能源、制造与网络，不只是 GPU。
   - 证据：https://blogs.nvidia.com/blog/nvidia-and-partners-build-in-america-for-america/
3. P1 — OpenAI 与美国政府持股构想进入公共讨论。
   - 重要性：若推进，会把前沿模型准入、公共利益和公司治理直接绑定。
   - 可能影响：仍无官方条款，不能据此判断模型发布政策或交易结果。
   - 证据：https://www.investing.com/news/stock-market-news/openai-proposes-handing-trump-administration-5-stake-ft-reports-4772283
4. P1 — Anthropic 恢复 Fable 5 / Mythos 5。
   - 重要性：模型可用性与政府准入规则继续成为企业采购变量。
   - 可能影响：客户需核对地区、渠道、使用限制与审计要求。
   - 证据：https://www.anthropic.com/news/redeploying-fable-5
5. P2 — GeneBench-Pro 延续科研 agent 可审计评估主线。
   - 重要性：评估从静态答题转向真实研究判断。
   - 可能影响：生命科学 agent 采购更重视路径、证据与失败模式。
   - 证据：https://openai.com/index/introducing-genebench-pro/
6. P2 — 银行业 AI 应用暂无窗口内新公告。
   - 重要性：固定栏目应保留真实缺口，不能用行情或宏观新闻补位。
   - 证据：https://www.hsbc.com/who-we-are/hsbc-and-digital/hsbc-and-ai
