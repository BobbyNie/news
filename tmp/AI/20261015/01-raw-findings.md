# AI 原始发现

## 1. Google DeepMind 与新加坡 GovTech 发布端侧反诈骗模型

- 发布时间：2026-10-14
- 来源：Google DeepMind
- 原文：https://deepmind.google/blog/on-device-ai-scam-detection-mddi/
- 可信度：official
- 中文摘要：双方将轻量 Gemma 模型用本地诈骗对话微调。模型在设备端分析对话模式，并在用户同意和分阶段部署条件下提示风险。官方说明训练数据不含私人或可识别个人数据。

## 2. Gemini 4 Argon 扩大到 Gemini 应用

- 发布时间：2026-10-13
- 来源：Google Blog
- 原文：https://blog.google/innovation-and-ai/products/gemini-app/gemini-4-argon-availability/

## 4. Ollama 与 Fly.io Sprites 支持受控 Agent 运行

- 发布时间：2026-10-13
- 来源：Ollama Blog
- 原文：https://ollama.com/blog/fly-io-sprites
- 可信度：official
- 中文摘要：Ollama Cloud 可以通过 Fly.io Sprites 在持久化 Linux 沙箱内运行。连接器默认阻断访问，并通过网关注入 API key，减少 Agent 泄露密钥的风险。

## 5. Android 扩展移动诈骗防护

- 发布时间：2026-10-14
- 来源：Google Security Blog
- 原文：https://blog.google/security/new-android-scam-protections/
- 可信度：official
- 中文摘要：Google 说明 Android 在电话、短信和聊天应用中增加 AI 驱动的诈骗检测和链接安全检查。官方给出每月拦截超过 500 万疑似诈骗电话和短信的说法。
