# 2026-06-10 AI 日报草稿

今天 AI 主线从“谁发新模型”扩展为三条并行线：Anthropic 直接发布 Fable 与 Mythos 5，OpenAI 把 AGI 广泛受益和资本结构放进治理叙事，AWS 则把 OpenAI open-weight models 与 Codex 接入 Bedrock，显示企业采用更重视云端治理、权限和软件开发 agent 工作流。

要闻：

1. Anthropic 发布 Fable 与 Mythos 5，强调自我博弈、长期任务执行和 multimodal reasoning。
2. OpenAI 发布 broad benefit 路线图，讨论研究自动化、安全协调、收益分配和必要时放缓前沿发展。
3. AWS 宣布 OpenAI open-weight models on Bedrock GA，并宣布 Codex on Bedrock GA，企业开发者工具链成为新竞争点。
4. NVIDIA 与 HPE、Samsung 推进 AI factory 合作，算力基础设施继续成为产业落地瓶颈。
5. OpenAI 称已向 SEC 保密递交 S-1 草案；AI 日报只作为治理与披露背景处理，估值与交易放入股市日报。
6. 金融业 AI 应用专栏：JPMorganChase 的 Evident AI Index 2025 继续说明银行 AI 采用正在从单点助手走向治理成熟度和规模化工具。

风险：Anthropic 新模型能力仍需独立评测；OpenAI 路线图和 S-1 是治理/资本结构信号，不等于新模型上线；AWS GA 需要观察企业实际迁移、权限隔离和成本结构。
