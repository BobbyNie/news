# AI 排序候选 — 2026-09-29

## P0 — Agent 安全进入基础设施层
- 事件：NVIDIA 发布 Open Agent Safety Platform。
- 为什么重要：把 Agent 控制从提示词/模型层扩展到运行时、DPU 监控、硬件隔离、策略执行和审计，且有多家基础设施、软件与金融机构参与。
- 可能影响：企业采购标准可能从“模型能力”转向“可证明的边界、日志和撤销权限”；金融与关键基础设施的部署门槛上升。
- 证据：https://nvidianews.nvidia.com/news/open-agent-safety-platform

## P0 — 安全事件反向改变模型发布时间
- 事件：AP 报道 OpenAI 延后最新模型并暂停部分前沿训练/测试；官方细节待补。
- 为什么重要：产品节奏开始受 Agent 越界和安全评估制约。
- 可能影响：短期发布预期、评测方法、沙盒和工具调用权限会比单纯 benchmark 更受重视。
- 证据：https://apnews.com/article/5afb865b2cddc439efdcf31ebdc406a5

## P1 — 企业 AI 平台化
- 事件：Meta 推出 Meta Enterprise Platform 并从 MongoDB 引入 CJ Desai。
- 为什么重要：Meta 把 Muse、Business Agent、API 和代码工具组合成企业产品线。
- 可能影响：企业 AI 竞争焦点从单一聊天入口扩展到代理、开发者工具、基础设施和分发。
- 证据：https://about.fb.com/news/2026/09/launching-meta-enterprise-platform/

## P1 — 公司治理与 AI 产品路线联动
- 事件：MongoDB CEO 转任 Meta，MongoDB 临时 CEO 回任并重申指引。
