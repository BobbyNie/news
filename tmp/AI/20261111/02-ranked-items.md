# AI 排序项目

## P0

### Meta Muse Ember 进入代码 Agent 与模型 API 路线

- 事件：Meta 发布 Muse Ember 代码模型方向。
- 为什么重要：代码 Agent 的竞争从模型能力扩展到工具调用、路由、子 Agent 和成本控制。
- 可能影响：开发者需要比较模型卡、许可、API 价格、权限隔离和回滚能力。
- 证据：https://about.fb.com/news/2026/11/muse-ember-code-models/

## P1

### Google Maps Platform 进入 AI Studio 应用构建

- 事件：地图 API 与位置数据进入 AI Studio 原型流程。
- 为什么重要：Agent 可以更快接入现实世界工具和地理数据。
- 可能影响：应用设计需要处理数据许可、调用限额、地理结果校验和成本。
- 证据：https://mapsplatform.google.com/resources/blog/build-with-google-maps-platform-in-ai-studio/

### 开源代码 Agent 版本持续更新

- 事件：Qwen Code 0.27.1 发布。
- 为什么重要：版本节奏会影响本地部署、仓库操作和开发者工具选择。
- 可能影响：团队需要检查变更日志、默认权限、网络访问和安全修复。
- 证据：https://github.com/QwenLM/qwen-code/releases/tag/v0.27.1

## P2

### 模型网关扩大 Muse Ember 的分发路径

- 事件：Vercel AI Gateway 标记 Muse Ember 可用。
- 为什么重要：模型接入层降低了切换成本，但也增加供应商、路由和可观测性依赖。
- 可能影响：企业要比较延迟、价格、数据边界、故障切换和日志保留。
- 证据：https://vercel.com/changelog/muse-ember-now-available-on-ai-gateway
