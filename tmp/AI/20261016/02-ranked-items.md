# AI 排名项目

## P0

1. **OpenAI 为数学 AI 结果建立研究支持机制**。它把模型产出、数学家复核和后续研究连接起来，重点转向可验证性与人机协作。证据：https://openai.com/index/sharing-ai-progress-in-mathematics/

2. **Gemini 4 Argon 进入 API 和 Google Cloud**。模型从展示性发布进入企业开发者平台，影响 Agent、编码和专业任务的部署评估。证据：https://cloud.google.com/blog/products/ai-machine-learning/gemini-4-argon-available-on-google-cloud

## P1

3. **Anthropic 评估联网设备上的自我复制风险**。风险面从数据中心扩展到消费级设备，推动设备签名、网络分段和异常行为监控。证据：https://www.anthropic.com/research/self-replicating-ai

4. **Google DeepMind 与新加坡 GovTech 推进端侧反诈骗模型**。端侧推理同时涉及隐私、金融反欺诈和移动平台部署。证据：https://deepmind.google/blog/on-device-ai-scam-detection-mddi/

5. **Ollama 与 Fly.io 提供持久化 Agent 沙箱**。Agent 运行时开始强调状态保存、网络隔离和密钥保护。证据：https://ollama.com/blog/fly-io-sprites

## P2

6. **Android 扩大 AI 诈骗防护**。它是端侧安全能力的产品化信号，但官方规模仍需要误报率和独立数据支持。证据：https://blog.google/security/new-android-scam-protections/
