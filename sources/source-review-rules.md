# 来源重检规则

每天生成日报前，必须先重检来源清单，再开始正式采集。

## 公共原则

- **报告日期**：一律使用 **Asia/Macau (UTC+8)** 日历日；Automation 以 `triggeredAt`（UTC）换算，**不得**使用系统注入的 UTC「今天」。Cron `0 23 * * *`（UTC）= 澳门次日 07:00 出报。
- 公开官方来源优先：公司官网、官方博客、RSS、投资者关系页面、SEC EDGAR、HKEXnews、交易所披露。
- 主流媒体次之：Reuters、Bloomberg、Financial Times、Wall Street Journal、The Information、TechCrunch、The Verge、MIT Technology Review 等。
- X/Facebook 只作为补充信号；除非能验证官方账号，否则不得作为唯一事实来源。
- 对无法访问、登录受限、疑似假账号、无原始链接的内容，必须写入报告的“来源覆盖与缺口”。
- 不静默删除来源。若认为来源失效，写入 `00-source-review.md`，说明证据和建议。

## 新增来源条件

新增来源必须满足至少一项：

- 官方公司、交易所、监管机构、投资者关系或新闻稿页面。
- 过去 24-48 小时内多家可信媒体反复引用的新重点公司或事件源。
- 新 IPO、上市聆讯、重大融资、监管调查、重大模型发布、重大产品发布、重大并购相关来源。
- 对 AI 或重点股票有持续高质量原始信息的论坛、研究社区或专题页。

## 社媒验证规则

引用 X/Facebook 内容前必须检查：

- 账号是否由公司官网、帮助中心、新闻稿或已验证官方页面交叉确认。
- 帖文是否与官方博客、新闻稿、IR 页面或主流媒体报道互相印证。
- 是否存在同名、仿冒、加密货币推广、异常链接或私信索要账号信息等风险。

如果只能找到社媒消息，报告中必须标注“待官方来源确认”。

## 临时文件要求

`00-source-review.md` 至少包含：

- 数据窗口。
- 新增建议。
- 失效或降权建议。
- 今日访问缺口。
- 需要人工确认的来源。

`01-raw-findings.md` 每条至少包含：

- 标题。
- 发布时间或发现时间。
- 来源名称。
- 原文链接。
- 可信度：official / major_media / market_disclosure / social_verified / forum / unverified。
- 中文摘要。

`02-ranked-items.md` 每条至少包含：

- 重要性等级：P0 / P1 / P2 / P3。
- 事件。
- 为什么重要。
- 可能影响。
- 证据链接。
